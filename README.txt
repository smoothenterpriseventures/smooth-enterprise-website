FREE GITHUB PAGES PUBLISHING
1. Create a free account at github.com.
2. Create a PUBLIC repository named YOURUSERNAME.github.io (replace YOURUSERNAME with your GitHub username).
3. Upload index.html, styles.css, and script.js to the repository root.
4. Under Settings > Pages, select Deploy from a branch, main, /(root), and save.
5. Your website will be available at https://YOURUSERNAME.github.io after deployment.
